# 梦幻小镇 · Merge Story — 技术架构文档

## 一、项目概述

一款基于 Merge-2 玩法的模拟经营类网页游戏，纯前端实现，使用 localStorage 进行数据持久化。

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 原生 JavaScript (ES6+) | 无框架依赖 |
| 样式 | CSS3 | Flexbox + Grid 布局 |
| 存储 | localStorage | 自动存档，每30秒+关键操作触发 |
| 部署 | Nginx | 静态文件服务 |

## 四、核心模块设计

### 4.1 GameState（游戏状态）
- 单例模式，管理所有游戏数据
- 包含：等级、经验、金币、钻石、能量、建筑、生成器、统计数据
- 提供序列化/反序列化方法

### 4.2 Grid（棋盘）
- 6×7 二维数组
- 点击拾取 + 点击放置合成
- 支持连锁合成（递归检查相邻格子）
- 提供物品交换、查找空位、获取邻居等方法

### 4.3 Generator（生成器）
- 每个生成器有独立冷却时间
- 支持点击类型和自动类型
- 概率产出不同等级物品
- 升级后冷却缩短、高等级产出概率提升

### 4.4 Order（订单）
- 主线订单 + 支线订单
- 订单模板按难度分级
- 只生成玩家已解锁物品链的订单
- 支线订单可同时接取最多3个

### 4.5 SaveManager（存档）
- 版本号管理，支持版本迁移
- 关键操作触发存档 + 每30秒自动存档

## 五、数据流

```
用户操作 → UI.js → Grid/GameState/OrderSystem → 更新状态 → 重新渲染 → 自动存档
         ↓
    Generator.js (定时器)
         ↓
    自动产出物品 → 放置到棋盘 → 重新渲染
```

## 六、物品配置

### 6.1 物品链
| 链ID | 名称 | 等级数 | 解锁条件 |
|------|------|--------|---------|
| bread | 面包链 | 6 | 初始解锁 |
| coffee | 咖啡链 | 6 | Lv.3 解锁咖啡馆 |
| flower | 花链 | 6 | Lv.5 解锁花店 |
| tool | 工具链 | 5 | Lv.7 解锁工坊 |
| decor | 装饰链 | 5 | Lv.9 解锁裁缝店 |

### 6.2 生成器冷却公式
```
实际冷却 = 基础冷却 × 0.85^(等级-1)
```

### 6.3 升级费用公式
```
建筑升级费用 = 80 × 1.4^(等级-1)
生成器升级费用 = 40 × 1.35^(等级-1)
```
