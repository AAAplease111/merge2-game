# 梦幻小镇 · Merge Story

一款基于 Merge-2 玩法的模拟经营游戏，灵感来自 Travel Town、Gossip Harbor 等经典游戏。

## 游戏地址

- **在线游玩**：http://45.40.228.244/merge/
- **GitHub**：https://github.com/AAAplease111/merge2-game

## 核心玩法

### 合成系统
- 6×7 棋盘，点击拾取物品，再点击另一个同类型同等级物品即可合成
- 合成后物品等级+1，获得经验值
- 支持连锁合成（合成后与相邻同等级物品自动继续合成）
- 物品等级越高，价值越高

### 生成器系统
每个生成器有独立的冷却时间，点击产出对应物品链的低等级物品：

| 生成器 | 对应建筑 | 解锁等级 | 类型 | 基础冷却 |
|--------|---------|---------|------|---------|
| 🧺 菜篮 | 🥖 面包店 | Lv.1 | 点击 | 2秒 |
| ☕ 咖啡壶 | ☕ 咖啡馆 | Lv.3 | 点击 | 3秒 |
| 🌸 花丛 | 💐 花店 | Lv.5 | 自动 | 15秒 |
| 🧰 工具箱 | 🔧 工坊 | Lv.7 | 点击 | 5秒 |
| 🪡 缝纫机 | 👗 裁缝店 | Lv.9 | 点击 | 6秒 |

### 订单系统
- **主线订单**：推进游戏进程，完成后自动生成下一单
- **支线订单**：额外奖励，可同时接取最多3个
- 订单只生成玩家已解锁生成器对应物品链的物品
- 订单从易到难，低等级订单只需要低等级物品

### 建筑系统
- 解锁建筑 → 解锁对应生成器 → 解锁对应物品链
- 升级建筑提升生成器效率
- 建筑升级费用递增

### 经济系统
- 🪙 **金币**：完成订单获得，用于升级建筑和生成器
- 💎 **钻石**：完成高难度订单获得，用于购买能量
- ⚡ **能量**：每3秒恢复1点，用于点击生成器（当前版本点击生成器不消耗能量）
- ⭐ **经验**：合成物品和完成订单获得，升级解锁新内容

## 技术架构

### 当前版本（v2.0 - 纯前端）
- **前端**：原生 JavaScript + CSS3 + HTML5
- **存储**：localStorage 自动存档
- **部署**：Nginx 静态文件服务

## 本地开发

```bash
# 克隆仓库
git clone https://github.com/AAAplease111/merge2-game.git
cd merge2-game

# 使用任意 HTTP 服务器运行
python3 -m http.server 8080
# 或
npx serve .
```
