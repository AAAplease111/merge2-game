# Merge-2 二合游戏 - 梦幻小镇 🏘️

一款基于 Merge-2 核心合成玩法的休闲手游技术原型。

## 🎮 在线试玩

直接打开 `index.html` 即可游玩，无需任何依赖！

```bash
# 方式一：直接浏览器打开
open index.html

# 方式二：启动本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 🏗️ 阶段规划

| 阶段 | 内容 | 状态 |
|------|------|------|
| **P0** | 纯前端原型（emoji 版，浏览器可玩） | ✅ 已完成 |
| P1 | 后端接入（Go + MySQL + Redis） | 📝 待开发 |
| P2 | Unity 客户端 + 美术 + 商业化 | 📝 待开发 |

## ✨ P0 功能

- 🎲 **6×7 棋盘** — 拖拽合成 + 连锁合成
- 🧺 **3 种生成器** — 菜篮（点击）、咖啡壶（点击）、花丛（自动 30s）
- 📋 **订单系统** — 主线订单 + 支线订单
- 💰 **经济系统** — 金币/钻石/能量/经验
- 🏪 **建筑升级** — 面包店/咖啡馆/花店
- 💾 **自动存档** — localStorage 持久化
- 🎨 **纯 emoji 视觉** — 3 条物品链（面包/咖啡/花）
